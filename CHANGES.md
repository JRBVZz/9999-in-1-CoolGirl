# Изменения в сборщике меню 9999-in-1

Краткое описание всех правок по порядку. Новые параметры задаются в `settings.ini`, секция `[menu]`.

## Новые параметры

| Ключ в `settings.ini` | Переменная в `config.py` | По умолчанию | Что делает |
|---|---|---|---|
|  | `SHOW_LIST_NUMBER` | `False` | Номер `0001.` перед именем игры |
|  | `SHOW_REPEAT_COUNTER` | `False` | Счётчик повторов списка `00..99` после имени |
|  | `LIST_SHIFT_LEFT` | `True` | Имя начинается с колонки 6 вместо 11 (если номера нет) |
| `intro` | `INTRO_DEFAULT_ON` | `False` | Заставка по умолчанию включена или выключена |
| `repeat_list` | `REPEAT_LIST` | `True` | `True` - 9999 слотов с повторами (как раньше), `False` - слотов ровно по числу игр |
|  (секция `[marquee]`) | `MARQ_PAUSE_ON_PROMPT` | `True` | Пауза бегущей строки, пока зажат Start или показана подсказка (действует только при `name_visible > 11`) |

Параметр `name_visible` уже был в проекте. Теперь он работает и со значениями больше 11 (см. п. 3).

## 1. Убрана нумерация списка и список сдвинут влево

- `fixed_bank.py`, `build_ext_draw_list_line`: цифры номера (4 цифры BCD и точка) и счётчик повторов выводятся только по флагам. Когда они выключены, ничего лишнего не пишется. Блок расчёта BCD оставлен как был, просто его результат не выводится.
- `config.py`: добавлены `LIST_LINE_COL = 6` и `LIST_NAME_COL` (6 при сдвиге влево, иначе 11).
- `marquee.py`: вместо жёсткого `adc #$4B` подставляется `0x40 + LIST_NAME_COL`, чтобы бегущая строка рисовала имя там же, где и список.
- Хвост строки после имени добивается пробелами только до исходной длины в 19 тайлов (`LINE_TILES`). Для длинных имён хвост короче или пропадает, иначе пробелы затирали фон справа.

## 2. Увеличение `name_visible` больше 11

Причиной глюков графики при движении курсора было переполнение буфера, а не нехватка ресурсов PPU.

- `config.py`: `RESTORE_BUF` (режим `name_mode=2`) перенесён с `$06E8` на `$0741`. Раньше в нём было ровно 11 байт, и запись при `name_visible > 11` портила соседние переменные (`CFG5007`, `IRQ_DIV_COUNTER` и другие). Новый диапазон `$0741..$0781` в режиме 2 не используется, там 65 байт.
- `config.py`: проверка `name_visible` при сборке. Значение должно помещаться в строку (максимум 26 при сдвиге влево и выключенных номерах и счётчике, 23 с включённым счётчиком повторов, 18 без сдвига или с номерами), в `NAME_MAX` и в `RESTORE_BUF`. Иначе сборка останавливается с понятным сообщением.

## 3. Заставка по умолчанию выключена

- `options_prompt.py`: `CFG_DEFAULT = CFG_MUSIC | (CFG_SPLASH if INTRO_DEFAULT_ON else 0)`.
- Значение по умолчанию применяется только тогда, когда в SRAM картриджа ещё нет сохранённых настроек. Если настройки уже записаны, заставку один раз нужно переключить в дополнительном меню.

## 4. Отключение повторов списка (`repeat_list = 0`)

Предел 9999 слотов зашит в оригинальном коде меню, поэтому правки затрагивают несколько файлов.

- `builder.py`: при выключенных повторах число слотов равно числу игр (`list_total`).
- `builder.py`: в оригинальной ROM подменяются непосредственные константы `$27`/`$0F` (то есть `$270F` = 9999):
  - конец списка при отрисовке страницы (`$C2D6`, `$C2DC`),
  - заворот вверх на нуле (`nav dec`, `$EBB7`, `$EBBB`),
  - заворот вниз на последней игре (`nav inc`, `$EBE7`, `$EBED`).
  Перед правкой билдер проверяет, что на этих адресах лежат ожидаемые байты, а также что по `$EC4D` лежит оригинальная пауза. Иначе сборка останавливается (другая версия оригинальной ROM).
- `fixed_bank.py`, `build_nav_page_norepeat`: новые процедуры листания страницами вместо оригинальных `$EBF8` и `$EC58`. Блок занимает около 72 байт, размещается в SAFE-2, если там есть место, иначе в основном окне. Билдер пишет в лог, куда он лёг.
  - Page down: на последней странице идёт на первую (строка 0), иначе прибавляет 16, а за концом списка встаёт на начало последней страницы.
  - Page up: вычитает 16, на первой странице идёт на начало последней страницы.
- `fixed_bank.py` (`build_load_state`) и `service_bank.py` (`build_service_load_state`): новый параметр `total_slots`. Сохранённая позиция за пределами списка сбрасывается в 0.
- Движение вверх и вниз по одной строке работает на оригинальных процедурах с подменёнными константами. На последней игре вниз ведёт на первую, на первой вверх ведёт на последнюю.

## 5. Мерцание и смена цветов при частом нажатии Start (`name_visible > 11`)

- Причина: Start запускает в NMI показ и скрытие подсказки (`prompt_show`, `prompt_hide`, `text_overlay`) и открывает доп. меню. Бюджет vblank для этого подбирался при `name_visible = 11`. Бегущая строка пишет `NAME_VISIBLE` тайлов за кадр, и при 20 символах вместе с подсказкой всё перестаёт помещаться в vblank. При `name_visible = 11` артефактов нет.
- `options_prompt.py`, `build_fixed_combined_nmi_hook`: пока Start зажат или на экране подсказка (`OPTIONS_PROMPT_SHOWN`), `marquee_nmi` в этом кадре пропускается. Это добавляет 11 байт и работает только при `name_visible > 11` и включённом `pause_on_prompt`. При значении 11 сгенерированный код не меняется.
- Побочный эффект: бегущая строка замирает, пока зажат Start.

## Затронутые файлы

`config.py`, `fixed_bank.py`, `marquee.py`, `options_prompt.py`, `service_bank.py`, `builder.py`.
